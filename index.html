OpsCommand

DevOps ekipleri için gerçek zamanlı işbirliği ve doğrudan Kubernetes API yönetimini bir araya getiren full-stack bir platform.

  • React + Node.js ile geliştirilmiş; WebSocket üzerinden canlı Kubernetes API entegrasyonu.
  • Pod logları, rollout ve scaling işlemlerini chat arayüzünden yönetebilen genişletilebilir OpsBot komut mimarisi.
  • Prometheus + Grafana ile özel PromQL sorguları kullanarak komut gecikmesi, hata oranları ve sistem kaynakları izlendi.

02
Cloud-Native 5G Core Deployment

Gerçek dünya telekom altyapısını simüle etmek amacıyla Kubernetes üzerinde 5G Core Ağı (Open5GS) ve RAN Simülatörü (UERANSIM) kurulumu.

  • Helm v3 ve Multus CNI ile çok bileşenli deployment workflow'ları otomatikleştirildi.
  • Kubernetes ClusterIP konfigürasyonları düzenlenerek kritik AMF-gNodeB SCTP bağlantı hataları giderildi.
  • uesimtun0 tünel arayüzleri ve ICMP probe ile uçtan uca 5G kullanıcı düzlemi bağlantısı doğrulandı.
